# Jarvis — STT в реальном времени

Локальное распознавание речи (multilingual) с нарезкой на аудио-чанки по паузам.

## Пайплайн

1. Микрофон режется на чанки по 32 мс (`audio.py`).
2. `SileroVAD` (`vad.py`) определяет речь на каждом чанке.
3. При старте речи чанк с пред-роллом (запас, по умолчанию 0.5 с) пишется в WAV.
4. При непрерывной тишине >= `--chunk-silence` (1.0 с) WAV отправляется в whisper.
5. Текст печатается строкой. Если пауза перед фразой была >= `--blank-pause`
   (2.0 с — больше средней речевой паузы), перед фразой выводится пустая строка.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

CUDA-библиотеки (cuBLAS/cuDNN) ставятся из `requirements.txt` в venv;
`run_stt.sh` выставляет `LD_LIBRARY_PATH`.

Захват звука идёт через `parec` (из пакета `pulseaudio-utils`) — он
корректно подключается к реальному источнику PipeWire. Установи при
необходимости:

```bash
sudo pacman -S pulseaudio-utils
```

## Запуск

```bash
./run_stt.sh                 # large-v3 на CUDA
./run_stt.sh --language ru   # принудительно русский
./run_stt.sh --list-devices  # список микрофонов
./run_stt.sh --keep-audio    # сохранять WAV-чанки в segments/
```

Модель Whisper скачивается с Hugging Face при первом запуске; VAD-модель —
автоматически при первом запуске.

## Параметры

| Флаг | По умолчанию | Назначение |
| :--- | :--- | :--- |
| `--model` | `large-v3` | Модель faster-whisper |
| `--device` | `cuda` | Без фолбека: при отсутствии CUDA — ошибка с подсказкой |
| `--language` | авто | Язык, напр. `ru` |
| `--pre-roll` | `0.5` | Запас аудио перед стартом речи, с |
| `--chunk-silence` | `1.0` | Тишина для завершения чанка, с |
| `--blank-pause` | `2.0` | Пауза для пустой строки, с |
| `--threshold` | `0.5` | Порог VAD |
| `--keep-audio` | — | Не удалять WAV |
